## 🚀 BestBlogs 自建版已成功部署！

恭喜！你的 **BestBlogs 自建版** 已经成功搭建。这是第一篇测试文章。

### ✨ 功能说明

- ⏰ **每日 6:00** — GitHub Actions 自动触发
- 🤖 **DeepSeek API** — 生成当日 AI 精选资讯
- 🔄 **自动提交** — 新内容自动 push 到仓库
- 🚀 **自动部署** — GitHub Pages 自动构建发布

### ⚙️ 还需要完成以下步骤：

1. **设置 DeepSeek API Key**
   - 前往 GitHub 仓库 → Settings → Secrets and variables → Actions
   - 添加 `DEEPSEEK_API_KEY`，值为你的 DeepSeek API Key
   - DeepSeek API Key 可在 [platform.deepseek.com](https://platform.deepseek.com) 获取

2. **启用 GitHub Pages**
   - Settings → Pages → Source 选择 "GitHub Actions"

3. **启用 Actions 权限**
   - Settings → Actions → General → Workflow permissions
   - 选择 "Read and write permissions"

4. **手动测试**
   - 前往 Actions 标签页
   - 选择 "Daily AI News Digest" workflow
   - 点击 "Run workflow" 手动触发
